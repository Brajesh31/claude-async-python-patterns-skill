## Installation

Copy the skill into your agent skills directory:

```bash
mkdir -p .claude/skills/async-python-patterns
cp SKILL.md .claude/skills/async-python-patterns/SKILL.md
```

Ask your AI coding assistant to use **Async Python Patterns** for a related task and follow the instructions in `SKILL.md`.
